# CV source content (markdown)

Markdown drafts and variants used when updating the live site. The Next.js app does **not** read these files at runtime — content is compiled into `libs/cv-data/src/data.ts`.

| File | Description |
|------|-------------|
| `PROFILE.md` | Main CV profile (formerly root `README.md`) |
| `SKILLS.md` | Skills reference |
| `CV-SKILLS.md` | Extended skills list |
| `junior_backend_cv.md` | Backend-focused CV variant |
| `cv-skills-ocean67.md` | Additional skills export |
| `_archive/` | Scratch / archived files |

Certificate and photo links in `PROFILE.md` point to `../legacy/certificates/` and `../legacy/photo/`.
